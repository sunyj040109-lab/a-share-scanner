# A 股盘中战法扫描

部署于 [sunyj040109-lab/a-share-scanner](https://github.com/sunyj040109-lab/a-share-scanner)。每个交易日北京时间约 14:00 准备 120 根已完成的历史日 K 线，约 14:25 抓取沪深主板、创业板、北交所全市场盘中行情，排除科创板，并生成 [手机报告](https://sunyj040109-lab.github.io/a-share-scanner/) 与 [REPORT.md](REPORT.md)。GitHub Actions 和 ChatGPT 日程都不能保证分钟级送达。

本项目把用户《选股模式与交易系统》转成可核查的 **pass / fail / unknown**。`unknown` 表示数据不足或规则无法客观判定，绝不等同于失败。程序不读取同花顺账户、个人持仓或自动下单。

## 每日流程

1. GitHub Actions 在工作日 UTC 05:07（北京时间 13:07）开始预热，检查交易日和代码。
2. 北京时间 14:00 抓取当日以前的 120 根日线：沪深优先腾讯、失败回退东方财富；北交所使用东方财富。接口失败、股票新上市或数据少于 120 根记为 `unknown`。预取最晚到 14:24。
3. 14:25 抓取腾讯全市场快照，以日线和盘中量价计算硬条件；对最多 60 只硬条件候选补取东方财富当日 5 分钟 K 线；读取同花顺行业概览和领先行业此前三日走势、上证指数盘中与历史数据。
4. 生成 `REPORT.md`、`docs/index.html`、CSV/JSON，并提交到 `main`。如果当日行情来源截断或错过窗口，任务失败或跳过，避免使用旧报告伪装当天数据。

GitHub cron 使用 UTC，休市由上海交易所日历判断。计划任务可能延迟甚至漏触发；读取方须再核对实际抓取时间和 `trade_date`。行情源不提供每只股票独立报价时间。

## 与选股 MD 的对应

| MD 条件 | 程序中的可检验代理 | 边界 |
|---|---|---|
| 大盘站上 5 日线 | 上证指数盘中价与含今日价的 MA5 比较 | 沪指只是全市场代理 |
| 地量后放量 | 最近 5 日最低量低于 20 日均量一定比例，盘中量较该低量放大 | 14:25 非收盘量，尾盘可能改变 |
| 持续领涨板块 | 同花顺当日行业涨幅、最近三日日线、上涨家数 | 只分析涨幅前 10 行业；尚无可靠全量个股行业/概念映射 |
| 近 120 日曾涨停 | 主板 10%、创业板 20%、北交所 30% 的收盘涨幅近似 | 新股无涨跌幅限制期、ST、除权及封板过程需人工核对；ST/退市整理排除候选 |
| 上升趋势 | 盘中价 > MA5 > MA20 > MA60，且 MA20 较 5 日前上行 | 使用未复权历史价；除权期可能失真 |
| 红色堆量 | 当日价高于昨日收盘且盘中累计量 ≥ 20 日均量的 1.5 倍；候选另查 10:00 后的 5 分钟红量柱 | 不能证明主力买入或主动成交方向 |
| 爆量阴线锚点、带量过顶 | 120 日最大量日为阴线时记录其高低点，比较盘中价与量 | 不是实际主力成本；跨除权价格需人工校验 |
| 连续堆量成本区 | 连续至少两根放量阳线的最低、高点与成交量加权收盘价 | 只是价格区间代理，不是筹码分布 |
| 一字板、上影线 | 历史开高低收近乎同价、最近 10 日上影线形态 | 无法判断封板中途是否被砸或上影线意图 |
| 跳空、回调倒锤/十字星 | 候选 5 分钟 K 线的开盘相对锚点、最近回调与末根形态 | 14:25 的信号可反转；14:30 后进场规则必须再复核 |
| 做 T、止盈止损、主力离场 | 报告保留 `unknown` | 需要个人持仓、止损线、分时均线及人工判断，程序不发交易指令 |

用户 MD 中的 **“历史涨停 + 上升趋势 + 红色堆量”** 是个股硬条件。报告列出的只是三个代理都 `pass` 的个股候选，并不代表大盘、板块、买点四层都通过。其它条件保存在 [逐股证据 JSON](docs/data/analysis.json)。阈值在 [config.json](config.json)，具体判定在 [strategy.py](strategy.py)。

## 输出

| 文件 | 内容 |
|---|---|
| `REPORT.md` | 大盘、板块、个股、买卖节奏四层手机简报 |
| `docs/index.html` | 手机网页 |
| `docs/data/universe.csv`、`.json` | 当天符合股票代码范围的全量快照 |
| `docs/data/selected.csv`、`.json` | 三个硬条件均通过的个股候选 |
| `docs/data/analysis.json` | 候选股逐项证据与 `unknown` 原因 |
| `docs/data/sectors.json` | 同花顺领先行业及最近三日代理 |
| `docs/data/summary.json` | 日期、抓取时刻、覆盖率、失败/未知数、大盘状态 |

CSV 为 UTF-8 with BOM；JSON 缺失值为 `null`。历史原始日线仅在当次 GitHub Runner 的临时目录使用，**不会每日整包提交到 Git 仓库**，避免仓库无限膨胀。

## 验证与限制

在 GitHub Runner 的 2026-10-22 接口探测中，腾讯沪深历史日线可用，腾讯北交所历史不可用；东方财富北交所日线与沪市 5 分钟 K 线可用，但北交所 5 分钟样本失败；同花顺行业概览可用，东方财富行业成分股接口断连。具体覆盖数以每日 `summary.json` 为准，不能因单个样本成功推断所有股票始终可取。免费接口可能限流或变更字段；真实全市场 120 日扫描耗时和稳定性需持续观察。

本地需要 Python 3.12+：

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python prepare.py --no-wait --sample 60 --output history.json
```

`scanner.py --history-file history.json` 仅在北京时间 14:25–14:35 的交易日运行。`prepare.py --sample` 用于接口抽样，不代表全市场报告。项目基于公开数据研究，不构成投资建议。
